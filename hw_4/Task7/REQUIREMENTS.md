# Task 7 — Run Two Controlled Prompt Iterations

Perform exactly two evidence-driven prompt revisions.

## Requirements

For each iteration:

- Select one prompt-addressable failure pattern.
- Change only the prompt.
- Run the prompt on all 10 tickets from Task 6.
- Determine whether outputs improved and whether any regressions occurred.
- Record a keep-or-revert decision.
- Begin Iteration 2 with the prompt accepted from Iteration 1. If the Iteration 1 prompt is rejected, use the original prompt.

## Deliverables

For each iteration, provide:

- The updated prompt.
- LLM outputs for all 10 tickets.
- An experiment log stating the targeted failure pattern and selection rationale, exact prompt change(s), observed improvements and regressions, and keep-or-revert decision with rationale.
