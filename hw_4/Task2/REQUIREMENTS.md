# Task 2 — Run a Controlled Classifier Iteration

## Requirements

- Make one targeted model or preprocessing change to address an addressable failure category from Task 1.
- Retrain using the Homework 3 training split.
- Evaluate against the Homework 3 validation set.
- Compare the candidate with the original baseline, identifying improvements and regressions.
- Make a keep-or-revert decision based on validation evidence.

## Deliverables

- Modified training and/or preprocessing code.
- Retrained model.
- Validation predictions in the same four-column CSV format as Homework 3.
- An experiment log stating the targeted failure category and changes, performance on records in that category, baseline validation metric improvements and regressions, and the keep-or-revert decision with rationale.
